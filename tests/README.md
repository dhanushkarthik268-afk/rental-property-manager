# Tests

`run_tests.sh` pipes scripted keyboard input into `rental_manager` and checks the output for expected lines.

Expected values were computed independently of the C++ code: totals, counts and balances were calculated directly from the CSV files by `expected_values.py` (Python, written separately from the C++ logic), then compared with what the program prints.

| Folder | Purpose |
|---|---|
| `data_empty/` | header-only files (empty input) |
| `data_malformed/` | sample data plus 10 deliberately bad lines |
| `data_crlf/` | sample data saved with Windows (CRLF) line endings |
| `data_missing/` | no CSV files at all |
| `data_large/` | generated by `gen_large.py`: 1,260 rooms, ~41,000 transactions |
